# Text Analyzer

A Python text analysis tool — built as a learning foundation.

## What it does

1. **Splits** — tokenizes raw text into individual words
2. **Counts** — tracks how many times each word appears
3. **Sorts** — returns words ranked by frequency

## Why I built this

This is the first stone of a larger project: a search engine built from scratch.
The goal isn't the tool itself — it's understanding how text processing works
at a fundamental level before building anything on top of it.

## Run it

```bash
python analyzer.py
```

## Stack

- Pure Python — no libraries, no shortcuts
- Isolated virtual environment (`.venv`)
